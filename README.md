## 🛠️ Tech Stack & Architecture
- **Structure**: Semantic HTML5 with comprehensive OpenGraph / SEO tags
- **Styling**: Vanilla CSS3 Custom Design System (no heavy frameworks, zero runtime overhead)
- **3D Graphics**: Three.js WebGL (ACES Filmic tone mapping, physical glass materials)
- **Interactions**: Custom magnetic cursor, smooth scroll orchestration, universal modal system
